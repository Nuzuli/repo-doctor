# Changelog

All notable changes to this project are documented in this file.

## [0.2.0] - 2026-11-14

### Added
- Three new checks: `contributing` (a CONTRIBUTING.md exists), `dependency_updates` (dependabot or renovate is configured), and `ci_runs_typecheck` (a workflow runs mypy or pyright). The tool now has 14 checks.
- `CONTRIBUTING.md` explaining how to set up the project and add a new check.
- `.github/dependabot.yml` for weekly updates of pip packages and GitHub Actions.
- `mypy` type check step in CI.

### Changed
- Check weights were rebalanced so the total is still exactly 100.
- README documents all 14 checks and shows real self-check output.

## [0.1.0] - 2026-11-10

### Added
- 11 repository health checks: lockfile, CI, tests, README, license, lint config, type config, .gitignore, changelog, and whether CI runs tests and lint.
- `repo-doctor` command with text and `--json` output.
- `--min-score` option that exits with code 1 when the score is too low.
- GitHub Actions workflow that tests on Python 3.10 and 3.12, type checks with mypy, and runs repo-doctor on itself.
- `requirements-lock.txt` for reproducible development installs, generated by a manual workflow.
